This will be the Meme Man game, a interactive choice survival game.

Here will be a start page with a button that takes you to the game pages, which have different button for different choices that take you other pages. When you die, a button takes you back to the start. If you win, then a Yay page will show where there is a button taking back to the home page.

Therw will be 12ish pages and the buttons have links in them for other pages. There will be images and text.
